# IYE Startup Project

DeepTech Vector Canvas platform.

## Architecture

This project is organized as a clean monorepo containing:
- `/backend`: Python service running FastAPI.
- `/frontend`: Vite frontend with Three.js/React-Three-Fiber.
- `/docs`: System documentation.

## Running Locally

Refer to individual READMEs inside `/backend` and `/frontend` for execution instructions.
